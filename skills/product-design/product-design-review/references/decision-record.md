# Decision Record

以既有格式為優先，缺少欄位增量補齊；不重編 ID。預覽時未發生的核准日期與同步狀態如實填 Pending，不預填已完成。

```text
Decision ID:
Domain ID:
Module ID:
Title:
Version:
Status:
Context:
Requirements:
Selected Approach:
Alternatives:
Rationale:
Trade-offs:
Risks:
Dependencies:
Affected Components:
Acceptance Criteria:
Supersedes / Superseded By:
Approval Date:
GitHub Sync Status:
```

Requirements 區分目標／非目標與發布範圍；Selected Approach 包含正常／失敗流程、責任及必要契約。Acceptance Criteria 使用可觀察的輸入／條件與預期結果。另列實作狀態及其證據，與設計狀態分開。風險接受、取代關係與核准均附可追溯來源。
